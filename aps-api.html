How It Works

Architecture
01

Domain Cache

Checks Cloudflare D1 for a previously seen verdict. Returns in <5ms if found.

02

AI Classification

New domains are evaluated by Llama 3.1 running on Workers AI. Result is cached for 7 days.

03

Edge Response

Verdict delivered from the nearest Cloudflare PoP. Globally sub-15ms for cached domains.

API Reference

v1.0
POST https://api.xivlabs.tech/scan

Scans a URL and returns a verdict. Requires an X-API-Key header for direct API access. The browser extension is exempt — it is identified by its browser origin automatically.

Request
// Headers
Content-Type: application/json
X-API-Key: aps_your_key_here

// Body
{
  "url": "https://example.com"
}
Response
{
  "blocked": false,
  "reason": "Base domain verified as safe in cache."
}

Quick Start
const res = await fetch("https://api.xivlabs.tech/scan", {
  method: "POST",
  headers: {
    "Content-Type": "application/json",
    "X-API-Key": "aps_your_key_here",
  },
  body: JSON.stringify({ url: "https://example.com" }),
});
const { blocked, reason } = await res.json();
