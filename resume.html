Projects

aps

Rust, Cloudflare Workers, D1, KV, Workers AI

Anti-phishing scanner that runs at the edge and gives a verdict on a URL in about 15 ms. Known domains are answered from a D1 threat cache, and new ones are classified with Workers AI. It has a public API with self-service keys and rate limiting.

hive and hive-blocklist

Rust, Python, Cloudflare Workers, GitHub Actions

Low-interaction SSH and HTTP honeypot that records every login attempt and probe without ever letting anyone in. A Cloudflare Worker feeds a live attack map and weekly public reports. GitHub Actions rebuilds a free blocklist every week in iptables, nginx and plain-text formats.

postburn

Rust, Durable Objects, WebCrypto

One-time secret links. The browser encrypts with AES-256-GCM, and the key stays in the URL fragment, so the server never sees it. Each secret lives in its own Durable Object and is deleted in the same step it is read, so it can be read once even when requests race. No server-side logs.

desk

Rust, WebRTC, Cloudflare Tunnel and Access

Self-hosted remote desktop for Linux in any browser: 1080p60 hardware-encoded H.264 over WebRTC, behind Cloudflare Tunnel and Access, with a password and TOTP.
